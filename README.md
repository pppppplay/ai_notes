# AI 課堂筆記

生成式 AI 課程的單元筆記與實作紀錄，純靜態網頁，用 GitHub Pages 發布。

## 內容

- **講義筆記**：每個單元整理成一頁（`notes/unitXX-主題.html`）
- **實作紀錄**：作業怎麼做、遇到什麼問題（`notes/lab-主題.html`）

## 新增筆記

規則寫在 [CLAUDE.md](CLAUDE.md)。簡單來說：

1. 複製 `templates/note.html` 到 `notes/`
2. 填內容
3. 在 `assets/notes.js` 的 `NOTES` 加一筆資料

首頁和上一篇／下一篇會自動更新。

## 本機預覽

直接用瀏覽器打開 `index.html` 即可，不需要安裝任何東西。
